QEMU では OS を起動していません。one-shot の試験は起動処理を模擬し、実機生成設定の表示試験では自動起動を止めています。実機での OS 起動を確認したことにはなりません。個別作業で導入した過去のテーマの実績も、新しいインストーラの試験とは区別しています。

検証機のバックアップ、ディスクイメージ、UUID、SSH 設定は公開ソースに含めません。
