# 困ったとき・元に戻す

SteamOS を起動できる場合は、保管してある展開フォルダーの **Ice Circuit セットアップ** を開きます。最初の画面から、状況に合う操作を選んでください。

| やりたいこと | 選ぶ項目 |
| --- | --- |
| 現在の状態を調べたい | **状態を確認**。詳しい確認には管理者認証が必要な場合があります。 |
| Ice Circuit の表示・設定を再適用したい | **設定を修復**。内容を確認して適用します。 |
| SteamOS 標準の起動方法に戻したい | **Ice Circuit を取り外す**。テーマと本ツールの設定を取り外します。OS・ゲーム・個人ファイルの削除ではありません。 |
| 直前の変更を取り消したい | **バックアップから戻す**。取り消したい変更を行った日時を選んで内容を確認します。 |

設定を書き換える操作は、認証後の確認画面で **戻る** を選べば適用しません。エラーが出た場合は、表示内容を保存してからセットアップを閉じてください。

取り外すと、Ice Circuit が追加した Windows の選択項目もなくなります。Windows 自体やゲームはそのまま残ります。

## バックアップについて

変更対象の設定は Deck 内の `/home/.ice-circuit/backups/` に保存されます。通常はこのフォルダーを直接操作せず、セットアップの **バックアップから戻す** を使います。

バックアップは、変更した起動設定のためのものです。ディスク全体や Windows の個人データのバックアップではありません。端末固有の設定を含むため、そのまま公開しないでください。

**直前の変更を戻す手順：**

1. セットアップの **バックアップから戻す** を選び、求められたら本体のパスワードで認証します。
2. 変更の完了画面に表示された **日時と、括弧内の6文字** が同じ記録を選びます。一覧は本体の時刻で新しい順に並びます。選んだ変更を行う直前の設定へ戻ります。
3. 内容を確認して **適用する** を選び、完了表示を待ちます。

復元済みの記録も一覧に残りますが、同じ記録は再利用できません。「復元済み、または復元できない状態」と表示されたら、**状態を確認** で現在の設定を確認してください。古い記録を順に試す必要はありません。

SteamOS 更新や別の操作で起動設定が変わった場合、古い状態への復元を停止することがあります。目的が Ice Circuit の取り外しであれば、**Ice Circuit を取り外す** を選び、その時点の SteamOS に合わせた内容を確認します。判断に迷う場合はエラーを控えて問い合わせてください。古い起動設定ファイルを手作業で上書きする必要はありません。

## メニューが出ない／起動項目がないと言われる

Ice Circuit は、電源を入れたときにどの OS へ進むかという、本体の起動登録を変更しません。テーマ設定だけでは直らない起動経路の問題があります。

既存の起動項目を確認するには、Deck をシャットダウンします。**音量＋を押したまま電源ボタンを押し、起動音が鳴ったら音量＋を離す** と起動メニューに入れます。十字キーと A ボタンで **Boot Manager** を選んでください。この入り方は [Valve の公式復旧案内](https://help.steampowered.com/en/faqs/view/65B4-2AA3-5F37-4227)にも記載されています。

一覧に **SteamOS** または **Windows Boot Manager** があれば、起動できるか確認します。SteamOS に戻れれば、セットアップの **状態を確認** を開いてください。

該当する起動項目がない場合は、Ice Circuit の再適用では復旧できません。画面の状況を添えて問い合わせてください。復旧資料にある初期化・再インストールの操作は、この確認のためには実行しません。

## 問い合わせる

[GitHub の Issues](https://github.com/cobo920/steamdeck-ice-circuit/issues)に、次を添えると状況を確認しやすくなります。

- 使用した Ice Circuit のバージョン（ダウンロードした ZIP の名前）。
- Steam Deck の LCD / OLED、SteamOS のバージョン、Windows のバージョン。
- 選んだ操作、画面に出たエラー、再起動後に表示されたもの。

パスワード・秘密鍵・バックアップ一式は添付しないでください。診断内容や画像を公開する前に、個人情報や端末固有の ID が写っていないか確認してください。
