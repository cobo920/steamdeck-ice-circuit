STEAM DECK · DUAL BOOT MENU · ALPHA.7

Ice Circuit を始めよう

SteamOS と Windows を選ぶ起動画面を、黒とアイスブルーの回路デザインに。

開発中の検証版です。実機確認済み：Steam Deck LCD / SteamOS 3.8.16 / Windows 10。

alpha.7 は alpha.6 と同じインストーラ・テーマを使い、導入案内と検証記録を更新した版です。

デザインプレビューです。実際の画面とは文字や余白が多少異なります。

始める前に
SteamOS と Windows がすでに入っていて、SteamOS を起動できる Deck が対象です。Windows の導入や、本体の起動登録の修復は行いません。認証には Deck 本体のローカルパスワード が必要です。未設定の場合は、下の補足を先に確認してください。

8つの手順

  1. デスクトップモードにするSTEAM → 電源 → デスクトップに切り替え。Steam が動いていれば STEAM＋X で画面キーボードを開けます。
  2. 導入用 ZIP を入手するGitHub Releases の Assets から Ice-Circuit-SteamDeck-0.1.0-alpha.7.zip を選びます。Source code は通常の導入用ではありません。
  3. Dolphin で展開するダウンロード / Downloads の ZIP を右クリックし、展開 → ここに展開。展開後のフォルダーを開きます。
  4. セットアップを開くInstall Ice Circuit.desktop（Ice Circuit セットアップ）を開きます。フォルダー全体を保管し、ランチャーだけを移動しないでください。
  5. 設定を選ぶ「インストール・設定変更」から、Windows の表示名・自動起動する OS・待ち時間を選びます。画像は標準のままで進められます。
  6. プレビューを見る「今の設定をプレビュー」でブラウザーが開きます。別の画面に隠れたらタスクバーから切り替え、確認後はセットアップへ戻ります。
  7. 認証して適用する「変更内容を確認して適用」を選び、Deck 本体のパスワードを入力します。Steam のパスワードや Windows の PIN ではありません。変更内容を確認して「適用する」を選び、完了まで待ちます。
  8. 自分のタイミングで再起動する完了画面とセットアップを閉じてから再起動し、メニューと両 OS の起動を確認します。起動項目がないという注意が出た場合は、先に起動経路を確認してください。

パスワードをまだ設定していない場合

本体のパスワードを未設定の場合だけ、一度だけ Konsole で passwd を入力し、新しいパスワードを2回入力します。文字や「*」が表示されなくても入力されています。現在のパスワードを求められて思い出せない場合は、いったん中止してください。詳しい手順 · Valve の公式説明

困ったとき

SteamOS が起動する場合は、セットアップの「状態を確認」「設定を修復」「バックアップから戻す」を使えます。「Ice Circuit を取り外す」はテーマと本ツールの設定を外す操作で、OS やゲームの削除ではありません。

ランチャーが開かない場合は、ZIP を全展開したフォルダー内で開いているか確認してください。プレビューはブラウザーの別画面に表示されます。
