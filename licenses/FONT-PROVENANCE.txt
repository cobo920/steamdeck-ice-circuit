Font provenance

Upstream project: DejaVu Fonts
License source: https://github.com/dejavu-fonts/dejavu-fonts/blob/master/LICENSE
License explanation: https://dejavu-fonts.github.io/License.html

DejaVu-Fonts-LICENSE.txt is the upstream license text, including Bitstream Vera
and Arev notices. It is copied unchanged into the built theme as
FONT-LICENSE.txt. Debian packaging license paragraphs are not used to describe
the font software. The complete upstream text also documents TeX Gyre DJV
Math and AMSFonts; those font files are not inputs to this theme.

Build inputs:
  DejaVuSans.ttf     -> sans-24.pf2, sans-32.pf2
  DejaVuSansMono.ttf -> mono-18.pf2

The build uses grub-mkfont to select U+0020..U+007E, U+00A0..U+00FF and
U+2190..U+2193. Converted font family names are Ice Circuit Sans and
Ice Circuit Mono. These names do not use the reserved Bitstream, Vera,
Tavmjong Bah or Arev names in the upstream notices.

The TTF files are build dependencies supplied by the DejaVu package. Their
SHA256 values are recorded in assets/manifest.json to identify the exact
inputs used for the checked-in PF2 files. Rebuilding with different versions
of the font files or rendering tools can change generated bytes.

The background and preview text is rendered with the same DejaVu font family.
The distributed theme retains the font license notice alongside the PF2 files.
